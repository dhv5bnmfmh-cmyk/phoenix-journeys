# Phoenix Story Quality Gate

> Story System Version：`1.0.0`  
> 状态：发布阻断规范  
> 最后整理：2026-08-01

任何故事母版、等级短文、特别 Journey 或相关学习内容，在进入 Preview 发布流程前必须通过以下十道 Gate。任何一道 Gate 未通过，禁止发布。不得通过提高阈值、删除测试、跳过等级、删减故事或改变统计口径放行。

## 判定等级

- **严重 Severe**：真实性、结构、文化、版权、流程、完整性或重大重复问题。立即阻断。
- **中等 Medium**：明显影响文学质量、阅读体验、学习价值或全库差异化。立即阻断。
- **轻微 Light**：不阻断理解与发布，但仍应在当前任务范围内尽量修正。

正式发布门槛：

```text
severe = 0
medium = 0
light 仅允许少量、明确、不影响出版质量的编辑建议
```

## Gate 1：故事结构

必须通过：

- 有明确进入、推进、变化、高潮、收束。
- 主角有当下目标。
- 至少一次行动或判断改变。
- 高潮由前文冲突造成。
- 结尾回收人物、物件、动作、问题或关系。
- 4 个母版 section 与运行时 1 至 2 段之间意义连续。

阻断：

- 只有景点介绍或资料堆叠。
- 第三段突然“明白”，但没有行动。
- 结尾与前文无因果。
- 低等级丢失目标或结局。
- 高等级用 filler 凑长度。

## Gate 2：角色

必须通过：

- 人物身份、目标、个性或错误判断清楚。
- 开场建立主角。
- 人物语言可辨认。
- 情绪通过行为变化。
- 选择产生后果。

阻断：

- 主角只是“你”或移动摄像机。
- 角色只负责讲知识。
- 所有人永远理性、正确、温和。
- 与现有角色在身份、任务、错误、高潮和结尾中有三项以上重复。

## Gate 3：文学质量

必须通过：

- 有画面、声音、动作和留白。
- 长短句与节奏有变化。
- 意象属于当前故事并参与叙事。
- 对话自然，旁白不过度总结。
- 结尾有余韵，不统一升华。

阻断：

- 流水账、AI 腔、模板四段。
- 连续抽象名词和对称句。
- 同一转折、比喻或升华句反复出现。
- 可以换地名后继续成立。

## Gate 4：阅读体验

必须通过：

- Lv.1–10 长度、段落与句法负荷符合政策。
- 段首指代清楚。
- 中文自然、可朗读。
- 拼音、越南语、英语按段对齐。
- 简繁转换不破坏专名与语义。
- 低等级不幼儿化，高等级不论文化。

阻断：

- 长度越界或段落数错误。
- 注释数量不匹配。
- 译文为空、错位或新增事实。
- 朗读句子过长、主语不明或语流僵硬。

## Gate 5：学习价值

必须通过：

- 生词来自 Story 或 Discovery。
- 例句真实包含目标词，且四种语言完整。
- Discovery 提供 Story 之外的新知识。
- Challenge 检查理解、篇章、语法、证据或动机。
- 回忆能指向人物、动作、选择或画面。
- HSK 与 TOCFL 校准不破坏自然中文。

阻断：

- 生词为凑数。
- Discovery 复述 Story。
- 挑战使用通用 filler 或明显错误答案。
- 高级内容只堆生僻词。

## Gate 6：Phoenix 流程适配

必须完整支持：

```text
故事 → 单词 → 发现 → 挑战 → 回忆 → 完成与盖章
```

必须通过：

- Journey ID、目录、地图、护照、背景、存储、来源一致。
- 三类挑战、三次机会、奖励和弱项复练正常。
- 回忆与盖章状态可保存、恢复且不串 Journey。
- 跟读不被塞回 Journey 主流程。
- “思考／表达”不恢复为公开步骤。

阻断：

- 只有故事入口，没有完整系统接入。
- 页面使用不同等级状态。
- 进度、奖励或盖章命名空间错误。

## Gate 7：文化真实性

必须通过：

- 普通 Journey 至少两条权威来源。
- 每个 story section 绑定 source ID。
- 事实、学术解释、争议、传说、原创清楚区分。
- 城市、民族、宗教、技艺和社区不被扁平化。
- 特别 Journey 尊重原典核心精神与文化语境。

阻断：

- 编造人物、日期、引语、机构、文物功能或 URL。
- 把传说写成事实。
- 把文化元素当异国装饰或猎奇对象。
- 现代网络小说化破坏原典精神。

## Gate 8：故事差异化

必须对照整个故事库检查：

- 主角身份
- 叙事任务
- 冲突类型
- 情绪曲线
- 高潮动作
- 结尾方式
- 主要意象
- 教育意义
- 节奏结构
- 城市与文化机制

自动与人工门槛：

- 正式母版任意两篇中文相似度不得超过既定 medium 阈值。
- 同一 narrativeMode、endingMode 不得重复注册。
- 通用时间／天气开场与保护式结尾比例不得超过 Gate 阈值。
- 等级短文不得共享连续的通用 enrichment 段落。
- 特别 Journey 必须使用类型专属扩展内容，不得落入普通城市扩展器。

阻断：

- 三项以上核心矩阵重复。
- 只换地名、角色名或物件。
- 全库主题和教育意义明显倾斜。

## Gate 9：AI 痕迹

必须检查：

- 四段是否过度整齐。
- 是否每段承担固定模板功能。
- 是否频繁使用“不只是、真正、共同形成、而是让”。
- 是否所有人物都用相同语气。
- 是否每篇都在结尾解释意义。
- 是否使用通用“观察颜色、声音、脚步、光线”补长度。
- 是否出现可批量替换的城市导览句。
- 是否为了文学感堆叠形容词、月光、风、回声、旧纸和脚印。

阻断：

- 明显生成式模板未被编辑消除。
- 高等级短文的新增句与人物、冲突和地点无关。
- 同一 AI 句型在多篇故事承担相同结构功能。

## Gate 10：最终评分

每篇故事从 100 分开始：

- Severe：每项扣 20 分，并立即 blocked。
- Medium：每项扣 8 分，并立即 needs revision。
- Light：每项扣 2 分。

正式 Story System 判定：

- `approved`：十道 Gate 全通过，severe = 0，medium = 0，分数至少 98。
- `needsRevision`：存在任何 medium 或分数低于 98。
- `blocked`：存在任何 severe。

整个故事库发布要求：

- 41 篇正式母版全部 approved。
- 41 Journey × 10 Phoenix Levels 全部 approved。
- 32 个普通 Journey 与 9 个特别 Journey 数量和注册一致。
- 全库文学、内容、来源、系统、图片和 Preview Gate 全部通过。
- 最低分 100，平均分 100.0，除非 Founder 明确批准新的非阻断计分政策。

## 必需发布证据

1. 全故事库总编辑审核记录。
2. Story Library 矩阵检查。
3. `JourneyLiteraryQualityAuditor` 报告。
4. 全等级内容质量报告。
5. Flutter Analyze。
6. Flutter 全量测试。
7. Flutter Web Release Build。
8. Cloudflare Worker 验证。
9. 当前 PR head 对应的 Preview 健康检查。
10. PR 保持 Draft，除非 Founder明确批准进入合并阶段。

## 失败后的处理

任何 Gate 失败时：

1. 记录具体故事、等级、句子和原因。
2. 判断是否为全库结构问题。
3. 优先修复严重，再修复中等，最后处理轻微。
4. 修改相关故事时同步检查整个故事库。
5. 重新执行全部十道 Gate。
6. 仍有提升空间时继续修改，不停在第一轮。
