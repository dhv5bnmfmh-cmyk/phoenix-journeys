# Phoenix Special Journey Guide

> Story System Version：`1.0.0`  
> 状态：特别 Journey 强制规范  
> 最后整理：2026-08-01

特别 Journey 不是普通城市故事加一层神秘滤镜。它应让 Explorer 进入中国文学、神话、志怪、传奇、民间与特殊文体中的核心问题，同时清楚区分原典、民间版本、学术解释与 Phoenix 原创。

## 1. 可使用来源

- 中国古典小说
- 志怪
- 传奇
- 神话
- 民间故事
- 口头文学
- 歌谣
- 谚语
- 诗
- 词
- 赋
- 散曲
- 笔记、公案、书信、日记、档案、碑记等特殊文体

来源必须可追踪。公版文本也不得大段复制，Phoenix 应进行原创学习叙事。

## 2. 当前特别 Journey 类型基线

当前 9 个特别 Journey 已形成不同叙事引擎：

- `literary-roaming`：庄周梦蝶精神下的双重日记与自我认知
- `myth-tracing`：月宫与桂树传说下的事实、传说、幻想档案
- `strange-night-talks`：志怪气质中的禁令、信任与求证
- `folk-secret-land`：逆流河灯与未来留言的伦理选择
- `changan-last-bus`：跨时代乘客、归途与运营责任
- `tide-letter`：潮声、旧录音与家庭记忆补白
- `arcade-lost-property`：骑楼雨季、多证人公案与关系修复
- `tea-horse-echo`：茶马古道、声音档案与社区许可
- `ice-city-star-map`：工业记忆、父辈复杂性与公共策展

新增特别 Journey 不得复制上述异常机制、核心问题、情绪曲线或结尾动作。

## 3. 尊重原典

尊重原典不等于逐字复述。必须保留：

- 核心精神
- 关键张力
- 文化象征
- 叙事气质
- 不确定性或思想问题

例如庄周梦蝶的价值不在“解开谁梦见谁”，而在自我与认知边界。改编不能把它变成抓住蝴蝶解除梦境的任务。

## 4. 合理改编

允许：

- 创作新的少年主角
- 使用现代阅读入口
- 重组视角和文体
- 将抽象思想转化为行动选择
- 加入明确标注的 Phoenix 原创情节
- 为语言学习调整篇幅与句法

不允许：

- 冒充原典续篇
- 伪造古人原话
- 改变原典核心伦理却不说明
- 把多个传统随意拼贴
- 用现代价值简单判决古典人物

## 5. 文学性

特别 Journey 必须保持：

- 独特叙述声音
- 类型专属意象
- 不完全解释
- 象征与行动的双层意义
- 节奏与气氛变化
- 能被朗读的自然中文

文学性不等于堆叠月光、薄雾、古琴、脚印和回声。

## 6. 神秘感

神秘感来自：

- 证据互相矛盾
- 规则存在空白
- 人物必须在不确定中选择
- 异常与现实同时有解释空间
- 读者知道部分真相，但不能掌握全部

神秘感不来自：

- 随机闪烁
- 无逻辑消失
- 每篇都有神秘旧物
- 结尾一句“原来一切是梦”
- 用怪力乱神替代人物选择

## 7. 文化价值

特别 Journey 应帮助 Explorer：

- 理解原典问题，而非记住故事梗概
- 认识不同版本和口头传统
- 分清文化意义与历史事实
- 学会尊重不确定性
- 看到古典问题如何与今天的责任、关系和表达相连

不能把文化价值压缩成统一道德结论。

## 8. 禁止现代网络小说化

禁止：

- 系统任务
- 等级升级
- 打怪掉落
- 天选之子
- 强制恋爱线
- 爽点反转
- 无限能力
- 现代网络热梗破坏语境
- 用“副本、NPC、Boss”解释传统世界

游戏化只存在于 Phoenix 学习流程，不侵入特别 Journey 的文学世界。

## 9. 异常规则

每个特别 Journey 必须定义：

- 异常如何出现
- 谁能感知
- 何时有效
- 有什么限制
- 人物付出什么代价
- 异常能做什么、不能做什么
- 结尾保留什么未知

异常不能替人物做决定，也不能自动修复关系。

## 10. 原典与原创标签

每个特别 Journey 内容包应记录：

- source type
- source title
- version or publisher
- public-domain or permission status
- core spirit
- protected elements
- adaptation notes
- Phoenix original plot
- fact／legend／original labels

Story、Discovery 与来源目录必须一致。

## 11. 特殊文体

特别 Journey 可采用：

- 双重日记
- 公案记录
- 家庭录音
- 运营日志
- 听证会
- 书信
- 口述证词
- 歌谣回环
- 诗词意象拼接
- 碑记与档案注释

特殊文体必须影响阅读和剧情，不能只是标题装饰。

## 12. 诗、词、赋、散曲改编

- 不大段复制原文。
- 必要短引文遵守版权与公版边界。
- 保留意象关系、节奏或情绪核心。
- 不把诗意解释成唯一标准答案。
- Discovery 可介绍格律、背景与不同解释。
- Story 负责让人物进入诗意问题。

## 13. 志怪与传奇

- 保留克制、陌生和日常世界被轻微撬开的感觉。
- 人物面对异常时仍需判断证据、信任和后果。
- 不用血腥、惊吓或恶意欺骗儿童。
- 不把民间信仰写成低级迷信。
- 结尾可开放，但必须回收人物行动。

## 14. 神话与民间故事

- 说明存在不同版本。
- 不声称唯一正统版本。
- 神祇、祖先、祭祀和地方传统保持尊重。
- 现代主角不应轻易“纠正”传统。
- 改编关注选择、关系和象征，不追求视觉奇观堆叠。

## 15. 特别 Journey 的学习闭环

- Story 保留类型气质与人物选择。
- 单词包含文体、意象、情绪和文化词。
- Discovery 解释原典、版本、象征和原创边界。
- Challenge 可检查视角、证词、隐含意义和文体。
- 回忆允许保留疑问，不要求唯一答案。
- 盖章体现该旅程的独特文学世界。

## 16. 等级适配

- Lv.1–2 保留异常规则、人物目标和结局，不把故事简化成“遇到怪事”。
- Lv.3–6 增加线索、对话、因果和版本边界。
- Lv.7–10 增加叙述视角、象征、伦理冲突和不可靠证词。
- 特别 Journey 必须使用专属扩展内容，不得进入普通城市 enrichment。
- 不同特别 Journey 不共享连续通用“光线、声音、脚下方向”句子补长度。

## 17. 发布阻断

以下任一项禁止发布：

- 原典或文化来源不清
- 核心精神被破坏
- 现代网络小说化
- 幻想冒充史实
- 与现有特别 Journey 异常机制重复
- 只靠神秘物件和天亮消失
- 文化或宗教表达猎奇化
- 高等级使用普通城市 filler
- Story Quality Gate 任一失败
