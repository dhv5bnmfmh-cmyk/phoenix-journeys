# Story Veracity and Culture Standard

Purpose

This standard governs factual accuracy, handling of folklore, cultural-fact-driven causality, and protections for real historical persons within Phoenix Journey Stories. It complements existing narrative and creation standards by mandating evidence-first workflows and clear labeling of unverifiable material.

Key principles

- FACT FIRST: Prioritize verifiable evidence before using a fact in Story causality.
- SOURCE HIERARCHY: Use authoritative sources in order: UNESCO/equivalent heritage authority → national/local government or museum/heritage authority → official cultural institutions → reputable academic or institutional sources. Cite exact evidence paths.
- UNVERIFIED FACTUAL CLAIM BLOCKER: Any materially affecting factual claim with no approved evidence must block Gold readiness and be recorded as `UNVERIFIED FACTUAL CLAIM — BLOCKED`.
- Real historical person protection: Do not assert real-person actions, motives, or dialogue unless supported by primary-source evidence. If used, flag as documented with citations. Prefer fictional proxies when evidence is absent.

Folklore and fictional material

- FICTIONAL CHARACTER IN VERIFIED HISTORICAL SETTING must be explicitly marked when fictional occupants or events are placed in a real verified setting.
- When presenting folklore or local legend, disclose in-story (or metadata) that "this is a local legend, not an established historical fact." Such disclosure is a cultural-literacy feature, not a bug.
- Do not present folklore as verified history; treat it as "cultural source material" that can inform character action only when explicitly framed as legend.

Cultural-fact action test (binding)

For every cultural fact that materially affects character action, the following chain must be documented:

1. cultural fact / place mechanism
2. character encounters it
3. character acts because of it
4. relationship or pressure changes
5. choice / cost / consequence changes

If any link is missing, the cultural fact fails the Cultural-Fact-Action Test and cannot be used to justify causal outcomes at Gold readiness.

Place causality and generic substitution test

- A Story must fail the GENERIC PLACE SUBSTITUTION TEST if replacing the named place with a generic site (park, museum, street) leaves Goal→Conflict→Choice→Climax→Consequence unchanged.
- Document why this place produces distinct causal pressure rather than being decorative.

Incremental cultural value

Every new Journey must document its incremental cultural value: why this Story adds culturally meaningful variance beyond existing Journeys or catalog entries.

Enforcement and gates

- Stories that introduce or depend on unverified factual claims must halt at the machine gate with `UNVERIFIED FACTUAL CLAIM — BLOCKED`.
- Folklore may be used as inspiration only when clearly labeled and when causal links are grounded in character action, not invented historical assertion.

Audit and traceability

- Record exact evidence paths (URLs, document titles, page numbers, archive identifiers) for every verified factual premise.
- Maintain a `PLACE_CAUSAL_MECHANISM` record for approved place-driven causal claims.
