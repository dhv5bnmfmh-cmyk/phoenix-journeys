# Forbidden City Journey Backlog

Status: planning only. Journey 01 (`两条路，一张图`) is the only Journey in the current product scope.

## Content rule

Each future Journey must answer one primary cultural question. It may carry no more than one or two secondary knowledge anchors. A backlog item does not authorize UI, story, challenge, background, or publication work.

## Journey 01 — active reference

- Primary question: 紫禁城的中轴与空间秩序，如何与人物任务共同影响路线理解？
- Secondary anchors: 午门；乾清门前的宫门、院落与东西向连接。
- Story: 沈砚、阿宁、周师傅的《两条路，一张图》。
