# 1. Purpose

Phoenix Visual Constitution（PVC）是 Phoenix Visual System 的最高规范。

它不是：

- 美术风格指南。
- 图片生成规范。
- 背景规范。
- 动画规范。
- UI 规范。

Phoenix Visual Constitution 回答的是：

> **Phoenix 为什么需要视觉。**

以及：

> **什么样的视觉，才属于 Phoenix。**

所有 Visual Documentation：

- VISUAL_PHILOSOPHY
- VISUAL_GUIDELINES
- BACKGROUND_GUIDELINES
- AI_IMAGE_GENERATION_GUIDE
- VISUAL_PIPELINE
- VISUAL_DECISION_TREE
- IMAGE_QUALITY_GATE
- VISUAL_CHECKLIST
- VISUAL_REVIEW_PROMPT
- COPYRIGHT_POLICY
- PERFORMANCE_GUIDE

全部必须遵守本 Constitution。

任何视觉规范不得违反本 Constitution。

---

# 2. Visual Mission

Phoenix 的视觉使命不是创造最华丽的画面。

Phoenix 的视觉使命是：

**帮助学习者进入故事。**

视觉不是学习目标。

视觉不是产品卖点。

视觉不是展示 AI 绘图能力。

视觉存在的意义，是帮助学习者相信：

这个世界真实存在。

只有当学习者相信这个世界。

阅读才会自然发生。

学习才会自然发生。

---

# 3. Visual Vision

Phoenix 希望建立一个长期成长的视觉世界。

这个世界应当：

拥有统一气质。

拥有统一审美。

拥有统一阅读体验。

但：

每一个 Journey。

都拥有自己的空间。

自己的光线。

自己的季节。

自己的文化。

自己的情绪。

Phoenix 追求：

整体一致。

局部独特。

---

# 4. Story Before Visual

Phoenix 永远坚持：

故事优先。

视觉服务故事。

不是：

故事服务视觉。

任何图片。

任何背景。

任何动画。

都不得要求故事为了视觉而改变。

如果视觉与故事发生冲突。

必须修改：

视觉。

不是故事。

---

# 5. Learning Before Decoration

Phoenix 的视觉不是装饰。

Phoenix 的视觉属于：

Learning Experience。

视觉必须帮助：

阅读。

理解。

记忆。

探索。

而不是：

吸引注意力。

任何视觉：

如果降低学习效率。

即使画得再漂亮。

也属于失败。

---

# 6. Reading Before Spectacle

Phoenix 相信：

阅读体验永远高于视觉震撼。

真正优秀的背景。

不会不断提醒学习者：

"看看这张图。"

真正优秀的背景。

会让学习者忘记背景。

专注于人物。

故事。

文化。

语言。

视觉的成功。

来自：

存在。

但不过度存在。

---

# 7. Visual Exists for Content

Phoenix 的视觉不是独立作品。

它始终服务：

内容。

Story 创造：

世界。

Visual 呈现：

世界。

Learning 创造：

学习路径。

Visual 支撑：

学习体验。

Visual 不创造：

故事。

Visual 不创造：

学习逻辑。

Visual 是内容表达层。

---

# 8. Authenticity

Phoenix 尊重真实。

无论：

现代城市。

古典文化。

历史 Journey。

神话 Journey。

视觉都应建立在：

真实文化。

真实空间。

真实生活。

合理想象。

之上。

不得：

为了画面效果。

破坏文化真实性。

不得：

创造不存在的传统。

不得：

错误混合不同文化。

---

# 9. Originality

Phoenix 的所有正式视觉资源。

必须具有：

原创性。

可追溯性。

商业可用性。

Phoenix 不允许：

复制。

拼接。

下载来源不明素材。

模仿具体艺术家。

复制电影镜头。

复制游戏画面。

复制动漫角色。

Phoenix 希望：

建立属于 Phoenix 自己的视觉语言。

而不是借用别人的视觉记忆。

---

# 10. Simplicity

Phoenix 相信：

克制。

比复杂更高级。

因此：

视觉应：

简单。

自然。

安静。

舒适。

留白。

具有呼吸感。

Phoenix 不追求：

炫技。

复杂特效。

密集细节。

高饱和冲击。

真正优秀的视觉。

能够长期阅读。

而不会令人疲劳。

# 11. Journey Identity

每一个 Journey。

都应拥有属于自己的视觉身份（Visual Identity）。

Visual Identity 不只是：

颜色。

背景。

建筑。

而是：

整个 Journey 给学习者留下的第一印象。

Visual Identity 应来自：

- 故事。
- 城市。
- 人物。
- 季节。
- 光线。
- 文化。
- 阅读节奏。

而不是：

随机选择颜色。

随机生成图片。

Phoenix 不允许：

多个 Journey 仅更换颜色而拥有相同视觉。

真正优秀的 Journey。

即使遮住标题。

学习者仍能辨认：

这是哪一个 Journey。

---

# 12. Visual and Culture

Phoenix 相信：

文化不是贴在背景上的装饰。

文化就是视觉本身。

真正优秀的视觉。

能够自然表现：

一个地方如何生活。

一个时代如何存在。

一种文化如何呼吸。

因此：

文化应体现在：

建筑。

街道。

自然环境。

器物。

服饰。

生活方式。

空间关系。

而不是：

大量文化符号堆积。

Phoenix 不鼓励：

"看起来很东方。"

Phoenix 希望：

"真正属于这里。"

---

# 13. Visual and Emotion

Phoenix 的视觉不仅表现空间。

更表现情绪。

情绪来自：

- 光线。
- 天气。
- 色温。
- 留白。
- 距离。
- 景深。
- 构图。

而不是：

大量特效。

Phoenix 不追求：

强烈情绪刺激。

Phoenix 更追求：

安静而真实的情绪体验。

学习者应能够通过背景自然感受到：

清晨。

傍晚。

等待。

团聚。

离别。

探索。

希望。

宁静。

而不是依赖说明文字。

---

# 14. Visual and Time

Phoenix 的世界拥有时间。

时间不是背景说明。

时间应自然存在于视觉之中。

例如：

晨光。

午后的阴影。

黄昏的暖色。

夜晚的灯火。

四季变化。

天气变化。

都应影响视觉。

时间让 Journey 更真实。

时间也让故事更可信。

---

# 15. Visual and Learning

Phoenix 的视觉始终服务学习。

视觉必须帮助学习者：

进入阅读。

保持注意力。

理解空间。

建立长期记忆。

视觉不得：

打断阅读。

分散注意力。

制造阅读压力。

Phoenix 希望：

学习者阅读结束后。

记住故事。

同时也记住：

那座城市。

那条街。

那片天空。

视觉帮助记忆。

不是抢夺记忆。

# 17. Relationship with Other Systems

Visual System 必须遵循 Documentation System。

同时与其它 Professional Systems 保持清晰边界。

## Visual × Story

Story 决定：

世界。

人物。

文化。

Visual 决定：

如何被看见。

Visual 永远不能改变：

Story 的核心意义。

---

## Visual × Learning

Learning 决定：

学习流程。

Visual 决定：

学习体验中的视觉环境。

Visual 不增加学习内容。

Visual 不改变学习目标。

---

## Visual × UI

UI 决定：

交互。

布局。

组件。

Visual 决定：

视觉语言。

光影。

空间。

氛围。

两者共同构成 Phoenix 的产品体验。

---

## Visual × Performance

Performance 决定：

资源如何高效运行。

Visual 决定：

资源应该呈现什么。

性能优化不得破坏视觉原则。

视觉设计也不得无视性能约束。

---

# 18. Permanent Principles

Phoenix Visual System 长期遵循以下不可改变原则。

## Principle One

Story Before Visual.

故事优先。

视觉服务故事。

---

## Principle Two

Learning Before Decoration.

学习优先。

视觉服务学习。

---

## Principle Three

Reading Before Effects.

阅读优先。

动画服务阅读。

---

## Principle Four

Authenticity Before Style.

真实优先。

风格建立在真实之上。

---

## Principle Five

Originality Before Convenience.

原创优先。

不得为了方便而使用来源不明素材。

---

## Principle Six

Consistency Before Novelty.

整体一致。

优先于局部炫目。

Phoenix 更重视：

长期品牌识别。

而不是一次性的视觉冲击。

---

## Principle Seven

Longevity Before Trend.

Phoenix 不追随短期视觉流行。

Phoenix 建立能够陪伴学习者长期阅读的视觉语言。

---

# 19. Permanent Rule

Phoenix 的视觉。

不是为了展示 AI 能力。

不是为了展示绘画技巧。

不是为了吸引短暂注意力。

Phoenix 的视觉。

始终服务：

故事。

阅读。

学习。

文化。

真正优秀的背景。

不会抢走故事。

真正优秀的图片。

不会抢走人物。

真正优秀的动画。

不会抢走阅读。

每一张 Phoenix 图片。

都应该像一本优秀绘本翻开的第一页。

每一个 Journey。

都应该拥有属于自己的世界。

Visual Constitution 是整个 Phoenix Visual System 的最高原则。

任何 Visual Documentation、Visual Development、Visual Review、Visual Pipeline、Visual Quality Gate 与 Visual Production，都必须遵守本 Constitution。
