# 特别旅程内容开发原则

## 核心定位

特别旅程用于承载具有中国古典文学、传统叙事与特殊文体特征的内容，不作为普通城市旅行故事的延伸。

## 内容来源范围

特别旅程的故事与学习内容，可来源于以下中国传统文学与文化类型：

- 中国古典小说
- 志怪与传奇
- 民间文学与口头传统
- 神话
- 传说
- 民间故事
- 歌谣
- 谚语
- 古典韵文与特殊文体
- 诗
- 词
- 赋
- 散曲

## 开发判断原则

符合上述来源、体裁或传统叙事特征的内容，优先归入“特别旅程”。

特别旅程应强调：

- 古典与传统文学气质
- 神话、志怪、传奇或民间叙事特色
- 诗性、韵律、象征与特殊文体体验
- 中国文化语境与文学审美

普通城市游览、现代生活故事、一般知识型内容，不应仅因题材稀有而归入特别旅程。
