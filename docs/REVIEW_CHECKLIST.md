# Phoenix Review Checklist

> 状态：合并与发布前强制检查  
> 最后整理：2026-07-31

Reviewer 应根据变更类型勾选相关项目。任何 `P0 / MUST` 项未通过，都不能合并或发布。详细规则以各专项规范为准，本文件只提供检查入口。

## 1. 任务与范围

- [ ] 已读取 `PRODUCT_PRINCIPLES.md`、`AI_DEVELOPMENT_GUIDE.md` 及相关专项规范。
- [ ] 当前变更来自最新批准基线，而不是旧 PR 或旧 Preview。
- [ ] 变更位于独立开发分支，没有直接修改 `main`。
- [ ] PR 保持 Draft，除非 Founder 明确要求进入合并阶段。
- [ ] 实际修改与用户要求一致，没有擅自扩展范围。
- [ ] 相邻但不阻断的问题已记录到 `TODO.md`，没有混入无关重构。

## 2. 架构与数据

- [ ] 使用现有共享目录、模型、服务和组件，没有建立平行系统。
- [ ] Journey ID、geo node、location binding 与存储命名空间一致。
- [ ] 进度、朗读位置、回忆、反馈、盖章和奖励按 Journey 隔离。
- [ ] 新字段有默认值、迁移策略和旧数据兼容测试。
- [ ] 没有在多个位置复制运行时目录数量。
- [ ] 没有通过删除测试或降低断言规避失败。
- [ ] 复杂业务逻辑位于可测试的服务或纯函数，不藏在 Widget 深层回调。

## 3. Journey 流程

- [ ] 公开步骤仍为：故事、单词、发现、挑战、回忆、完成。
- [ ] 未重新加入“思考/表达”步骤、进度标签或入口。
- [ ] 未把跟读训练重新嵌入 Journey 流程。
- [ ] 未完成 Journey 只能顺序前进或返回相邻步骤。
- [ ] 完成后可回看，盖章与分享状态正确。
- [ ] 退出、重进和切换 Journey 后状态恢复正确。

## 4. UI 与移动端

详见 `UI_GUIDELINES.md`。

- [ ] iPhone 窄屏和矮屏无 overflow、遮挡或被迫横向滚动。
- [ ] 主页面保持一屏框架，没有水平 `PageView`。
- [ ] 内容过长只在受约束区域内滚动。
- [ ] AppBar、等级控制、简繁切换和底部按钮几何稳定。
- [ ] 使用 `PhoenixTheme` 与共享面板、按钮、字体 token。
- [ ] 文字在最亮和最暗背景上均可读。
- [ ] 图标按钮有 tooltip 或语义标签。
- [ ] 键盘打开时输入与提交可见，固定导航不会遮挡。
- [ ] 持久 FocusNode 未因 rebuild 丢失。
- [ ] 降低动态效果模式可用。
- [ ] 动效无闪烁、假水波、廉价粒子或正文抖动。

## 5. 简繁与多语言

- [ ] 所有 Explorer 可见中文经过统一 script conversion。
- [ ] 简体模式没有繁体残留，繁体模式没有简体残留。
- [ ] Story、Discovery、挑战、错误、加载与分享文案一致。
- [ ] 拼音带声调，专名与多音字已复核。
- [ ] 越南语自然、完整，没有机械中文语序。
- [ ] 英语自然、术语一致。
- [ ] 翻译没有增加原文或来源未支持的新事实。

## 6. 朗读与高亮

- [ ] 音频、进度、当前字词与高亮使用同一个 Controller offset。
- [ ] Story 与 Discovery 保存独立位置。
- [ ] 首次播放在 iOS Safari 用户手势链内启动。
- [ ] 暂停后从相同位置继续。
- [ ] 语速变化后从相同位置继续。
- [ ] 临时词语或辅助语言朗读后恢复原位置。
- [ ] 打开或关闭词语详情不会丢失播放状态。
- [ ] 恢复页面时不会未经用户操作自动播放。
- [ ] 失败时显示明确重试，不会假装“播放中”。
- [ ] 语速范围仍为 0.5x–1.5x、0.1x 步进、默认 1.0x。
- [ ] 高亮只作用于文字，没有独立色条、整段背景或跳动装饰。

## 7. 新增或修改 Journey

详见 `STORY_GUIDELINES.md`。

- [ ] Journey 元数据完整且目的地专属。
- [ ] 新基础故事包含 4 个 section。
- [ ] 每个 section 有稳定 ID 与 source ID。
- [ ] 4 组中、拼、越、英阅读支持顺序对齐。
- [ ] 新普通 Journey 至少 9 个不重复词语。
- [ ] 每个新增或修改词语有真实例句，且例句实际包含目标词。
- [ ] 基础 Discovery 候选完整，运行时每级显示 1–2 条。
- [ ] `wonderQuestion` 与 `expressQuestion` 非空且不同，但未变成公开步骤。
- [ ] Lv.1–10 保留开场与结尾含义。
- [ ] 高级等级没有通用 filler。
- [ ] 三种挑战都保持 Journey 主题。

## 8. 来源与真实性

- [ ] 每个 Journey 至少两条权威来源。
- [ ] 核心事实由 UNESCO、政府、博物馆或学术来源支持。
- [ ] source ID、URL、发布者、类型、语言、geo node 和状态完整。
- [ ] 来源状态为 `verified` 或 `published`。
- [ ] 每个 Story section 可追踪到来源。
- [ ] 传说使用“相传”等明确措辞。
- [ ] 学术争议没有被写成唯一事实。
- [ ] Phoenix 原创内容已清楚标注，不冒充古籍或史料。
- [ ] 没有虚构日期、人物、引语、机构或 URL。

## 9. 词语与 Discovery

- [ ] 词语无空值、重复或与内容无关的凑数项。
- [ ] 定义包含中文、母语与英语。
- [ ] 多义词使用当前 Journey 的正确义项。
- [ ] Discovery 每条提供 Story 之外的新信息。
- [ ] Discovery 至少 8 个有效中文字符。
- [ ] Discovery 之间不重复，也不高度重复 Story。
- [ ] 所有四语言字段完整。

## 10. 挑战与奖励

- [ ] 固定三种挑战模式。
- [ ] 每种模式固定 4 个候选答案。
- [ ] 候选答案唯一、长度平衡、完整显示。
- [ ] 错误选项可信且主题专属。
- [ ] 每种模式最多 3 次机会。
- [ ] 第 1 / 2 / 3 次正确分别奖励金币 / 银币 / 铜币。
- [ ] 三次未正确奖励碎银并展示正确答案。
- [ ] 奖励 ID 可防重复领取。
- [ ] 弱项复练不重复奖励。
- [ ] 讲解包含训练目标、掌握状态、原因和记忆方法。

## 11. 地图、护照、背景与资产

- [ ] 地图坐标与真实城市位置一致。
- [ ] 航线、缩放和落点连续且只播放一次。
- [ ] 抵达后只显示当前城市目的地。
- [ ] 护照使用透明城市分组与紧凑 Journey tile。
- [ ] 特别 Journey 入口正确显示钱包与解锁状态。
- [ ] 盖章动效与最终印记位置正确。
- [ ] 每个发布目的地有 10 个有效离线背景位置。
- [ ] 特别 Journey 有 10 个与故事对应的场景位置。
- [ ] 资源为原创、项目自有或拥有授权。
- [ ] 无品牌角色、商标、艺术家仿作、水印、灰柱或低清拉伸。
- [ ] `pubspec`、目录、映射和测试同步。

## 12. AI、隐私与安全

- [ ] Flutter 未直接调用模型供应商或保存服务端密钥。
- [ ] 请求通过唯一 AI 总编排器与服务端网关。
- [ ] 专业 Agent 使用当前 Journey 的审查上下文。
- [ ] 输出经过 schema 验证与隐藏质量审查。
- [ ] 模型失败时有安全回退，基础 Journey 不被阻断。
- [ ] 用户学习记忆已限制字段、长度和数量。
- [ ] 私人正文没有被服务端永久保存。
- [ ] 日志不包含 API Key、完整私人写作或内部提示。
- [ ] 健康状态如实显示 provider 与 fallback。

## 13. 自动化测试

- [ ] `node --test worker/*.test.mjs`
- [ ] `flutter pub get`
- [ ] `flutter analyze`
- [ ] `flutter test`
- [ ] `flutter build web --release`
- [ ] Worker bundle 验证
- [ ] 新逻辑有针对性单元或契约测试
- [ ] 历史高风险区域有回归测试
- [ ] 测试名称描述真实当前规则，没有保留误导性的旧数量或旧流程名称

## 14. 内容品质报告

详见 `CONTENT_QUALITY.md`。

- [ ] 报告覆盖所有 Journey × Phoenix Lv.1–10。
- [ ] `blockedCount = 0`。
- [ ] `needsRevisionCount = 0`。
- [ ] 最低分为 100。
- [ ] 平均分为 100。
- [ ] Journey 数量与检查组合正确。
- [ ] 报告 artifact 已上传。
- [ ] PR quality comment 已更新。
- [ ] 发布判定在 Web build 和部署之前执行。

## 15. Preview 与 PR

- [ ] Preview 使用独立 PR Worker。
- [ ] Checkout 的是 feature head commit，不是 merge ref。
- [ ] Preview URL 指向当前 commit 版本。
- [ ] 全开放体验参数正确。
- [ ] Preview health 证明当前 commit 已部署。
- [ ] PR 评论中的旧链接已被当前链接更新。
- [ ] 其他 PR 与正式版未被覆盖。
- [ ] PR 描述包含功能、验证、风险、迁移和未完成项。

## 16. 文档

- [ ] 产品原则变化已更新 `PRODUCT_PRINCIPLES.md`。
- [ ] UI 契约变化已更新 `UI_GUIDELINES.md`。
- [ ] 内容格式变化已更新 `STORY_GUIDELINES.md`。
- [ ] Gate 变化已更新 `CONTENT_QUALITY.md`。
- [ ] 路线图或 TODO 已同步。
- [ ] `CHANGELOG.md` 已记录用户可感知或流程级变更。
- [ ] 没有把同一完整规则复制到多份文档。

## 17. 合并前 Founder 确认

- [ ] CI 与 Preview 全部成功。
- [ ] Founder 已体验当前 Preview。
- [ ] Founder 已明确同意合并 `main`。
- [ ] 合并后发布与回滚方式清楚。

没有 Founder 的明确合并批准，不得执行最后一步。
