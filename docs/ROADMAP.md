# Phoenix Roadmap

> 状态：方向性文件，不是发布日期承诺  
> 最后整理：2026-07-31

本文只描述 Phoenix 的阶段目标与先后关系。具体可执行事项放在 `TODO.md`，固定产品原则见 `PRODUCT_PRINCIPLES.md`。

## 1. 当前基线

当前体验版已具备：

- Flutter 移动 Web 原型与独立 PR Preview
- Phoenix Lv.1–10 统一等级
- 固定六步 Journey：故事、单词、发现、挑战、回忆、完成
- 普通旅程与特别旅程统一目录
- 地图抵达、城市目的地、护照、盖章与分享
- 简繁切换、越南语与英语辅助
- Story / Discovery 朗读、进度、高亮、续播和语速控制
- 三类挑战、三次机会、奖励货币与重点复练
- 特别旅程货币解锁
- 独立跟读训练入口
- AI Agent 编排、知识约束、客户端隐私记忆和质量审查
- 全目录内容品质 Gate、Flutter CI 与 Cloudflare Preview

当前数量与版本快照记录在 `CHANGELOG.md`。

## 2. 路线图原则

1. 先稳定学习体验，再扩大内容数量。
2. 先完成统一系统接入，再发布新旅程。
3. 先保证 iPhone、Safari、朗读和键盘可靠，再增加复杂动效。
4. 先建立内容来源与品质 Gate，再使用 AI 扩张内容。
5. 付费能力不得降低免费内容品质，也不得引入广告或焦虑式留存。
6. 新阶段开始前，必须清理对应阶段的 P0 阻断项。

## 3. Phase A：开发治理与稳定基线

**状态：进行中**

目标：让任何新的 AI 开发会话只读取仓库即可安全继续。

完成标准：

- 建立并维护 `docs/` 九份核心规范
- 当前 PR、Preview、质量报告和合并规则清晰
- 规则不再散落在聊天记录、旧 PR 和重复测试说明中
- 新规则能映射到代码、测试或 Review Checklist
- README 不再与当前产品状态冲突

## 4. Phase B：核心体验硬化

**状态：下一阶段重点**

目标：让所有现有 Journey 在移动端稳定、清晰、自然。

范围：

- iOS Safari 朗读启动、暂停、续播、语速和高亮回归
- Story、Discovery、单词弹层与挑战在小屏幕的一屏体验
- 键盘打开时的输入区域、按钮和导航安全
- 世界地图到城市的真实路线、缩放与落点
- 护照透明地图、城市热点与紧凑盖章布局
- 简繁全局一致性
- 降低动态效果、性能与可访问性
- 清理不再公开的旧流程兼容代码，但必须先完成数据迁移与测试

退出标准：

- 关键移动端回归测试稳定
- 所有 PR Preview 可验证当前 commit
- 无已知 P0 朗读、页面遮挡、流程阻断或状态丢失问题

## 5. Phase C：内容体系扩张

**状态：持续进行**

目标：按统一规格稳定扩充普通旅程与特别旅程。

范围：

- 分批新增高质量普通旅程
- 每个新旅程完整接入故事、单词、发现、挑战、回忆、盖章、地图、护照与背景
- 继续扩展文学、神话、民间、奇闻等特别旅程
- 每个目的地建立经过审查的离线背景库
- 每个故事建立权威来源、地理绑定和多语言支持
- 提升高级等级内容，避免通用填充与重复发现

退出标准：

- 新增 Journey 全部通过 Lv.1–10 品质 Gate
- 内容规模增长不增加重复目录、手工计数或无来源内容
- 图片与故事资产均可追踪授权或原创来源

## 6. Phase D：学习智能与复习闭环

**状态：规划中**

目标：让 Phoenix 根据学习表现安排下一步，而不是只展示内容。

范围：

- 根据挑战表现识别薄弱能力
- 将低分项导入重点复练，不重复发放奖励
- 我的单词、例句和 Journey 上下文复习
- 跟读发音诊断、弱句复练和等级适配
- Phoenix Lv.1–10 校准与长期进步记录
- AI Guide / Writing 等能力以独立、非阻塞方式提供，不恢复旧 Journey 步骤
- 客户端隐私记忆的可查看、可删除与边界控制

退出标准：

- 学习建议可解释、可关闭、可重复验证
- AI 失败不会阻断基础 Journey
- 用户数据不因智能化而失去隐私边界

## 7. Phase E：产品化与商业准备

**状态：后续**

目标：从 Founder Prototype 进入可持续运营版本。

范围：

- 账户、跨设备同步和恢复机制
- 免费 Explorer 上午一次、下午一次的稳定分配
- 付费 Explorer 无限普通 Journey 容量
- 特别旅程货币与解锁经济的正式平衡
- 支付、订阅恢复与权限验证
- 隐私友好的产品分析与错误诊断
- 发布渠道、版本管理、支持与数据迁移
- 越南语、英语及后续市场本地化

退出标准：

- 权限和支付不会破坏本地离线学习
- 免费与付费规则有测试、有文档、有恢复路径
- 无广告、无强迫式留存、无秘密数据出售

## 8. Phase F：世界语言旅程

**状态：远期愿景**

目标：在中文产品稳定后，把 Phoenix 扩展为世界文化与语言旅程平台。

前置条件：

- 中文内容体系、等级、来源和复习闭环成熟
- Journey 模型不依赖单一城市或单一语言的硬编码
- 多语言语音、脚本、文化审核和地理系统可扩展

本阶段不得提前牺牲当前中文体验的完整性。

## 9. 暂不进入路线图的事项

以下内容没有 Founder 明确决定前，不得作为既定功能开发：

- 第三方广告
- 强制签到、连续天数惩罚或焦虑式留存
- 将核心故事质量区分为免费低配与付费高配
- 未经许可的社交排行榜
- 服务端永久保存私人学习内容
- 碎银兑换比例、特别旅程价格或新货币的最终数值
- 自动合并 `main`

## 10. 路线图更新方法

- 新阶段必须有目标、范围和退出标准。
- 具体任务只写入 `TODO.md`，不要在两处维护相同清单。
- 已完成的重要里程碑移入 `CHANGELOG.md`。
- Founder 改变产品方向时，先更新 `PRODUCT_PRINCIPLES.md`，再调整本文件。
